# WatchMonitor 技术指标分析

> 分析范围：`WatchMonitor` 及其同级共享包 `trading_ai_toolkit\indicators`。本文基于源码静态梳理，不构成投资建议。

## 1. 结论概览

项目采用两层技术分析：

1. **指标层**：共享 `indicators` 包实现 MA、SuperTrend、MACD、RSI、ADX、量价与 K 线形态；`IndicatorManager` 依据 `config/indicators.yaml` 调度并加权评分。
2. **趋势场景层**：`core/trend` 先以 MA、SuperTrend 与价格位置判定上升、下降或横盘，再针对对应场景输出顶部、底部、突破或企稳信号。

实际报告入口 `report.py` 调用 `IndicatorManager.analyze_stock(..., force_realtime=True)`，因此报告默认使用当次日 K 数据实时计算，而不是依赖 `technical_indicators` 的预计算缓存。ADX 是例外：个股 ADX 优先读取 `adx_score` 表；指数 ADX 在本地以日 K 实时计算。

```text
日K（open/high/low/close/volume/date）
        │
        ├─ 指标层：IndicatorManager（7 个指标） ─→ 信号 / 报告行 / 加权分
        │
        └─ 趋势层：TrendDetector ─→ 上升 / 下降 / 横盘场景 ─→ 场景信号
                                                        │
                                            持仓风险与候选池抄底报告
```

## 3. 指标公式、参数与业务解释

### 3.1 ATR 与 SuperTrend

**ATR（Average True Range）**

- 真波幅：`TR = max(high-low, |high-prev_close|, |low-prev_close|)`。
- ATR 使用 Wilder RMA：首值为前 `n` 个 TR 的均值，之后 `ATR_t = (ATR_(t-1) × (n-1) + TR_t) / n`。
- 这是波动率而非涨跌方向指标，供 SuperTrend 计算动态轨道。

**SuperTrend**

- 基础轨：`HL2 ± multiplier × ATR`，其中 `HL2 = (high + low) / 2`。
- 上下轨会按前一日收盘及前一最终轨道“延续”，避免轨道在趋势中反向移动。
- 多头状态下，收盘跌破最终下轨即翻空；空头状态下，收盘上破最终上轨即翻多。
- 配置参数为 `atr_period=10`、`multiplier=3.0`，权重 `2.0`；多头原始分 `+2`，空头 `-2`。
- 持仓风险：检测日线翻空；若周线也翻空则附加“极高风险”信号。报告会显示方向及现价距离反转轨的百分比。

注意：即时指标对象会使用 YAML 的 10 日 ATR；而 `calculate_all_indicators`、翻转检测和趋势检测直接使用 90 日 ATR（周线翻转函数内部使用 20 日）。同一份报告中“方向、缓存、翻转、趋势评分”可能因此来自不同参数体系，见第 7 节。

### 3.2 MA 均线与均线结构

- 简单移动平均：`MA_n = 最近 n 日收盘价之和 / n`。
- 配置计算周期：`5、10、20、60、120、250`；斜率观察周期：`5、10、20`。
- 斜率为今天 MA 减昨天 MA：变化大于当日 MA 的 `0.1%` 记为 `+1`，小于 `-0.1%` 记为 `-1`，其余为走平 `0`。
- 金叉/死叉由昨日与今日的快、慢 MA 相对位置交叉确认。

持仓信号与评分：

- 现价跌破 MA5 / MA10 / MA20，分别给出中 / 高 / 高风险提示；MA20 提示“支撑失效”。
- MA5 斜率向下给出抵扣价及维持均线上扬所需涨幅。
- 原始评分：价高于 MA5 `+1`，低于 MA5 `-1`；价高于 MA10 `+1`，低于 MA10 `-0.5`；MA5 向上/下 `+1/-1`；MA10 向上/下 `+0.5/-0.5`。该指标权重为 `1.0`。

### 3.3 MACD 与背离

- `EMA_n` 使用 `alpha = 2 / (n + 1)`、`adjust=False` 的指数平均。
- `DIF = EMA_12(close) - EMA_26(close)`；`DEA = EMA_9(DIF)`；柱状图 `= 2 × (DIF - DEA)`。
- YAML 参数为 `12/26/9`，权重 `1.0`。
- 项目不是以 DIF 与 DEA 金叉评分，而是比较柱、DIF、DEA 最近两日变化；每条线变化绝对值超过 `0.01` 才认定上升/下降。三线组合会输出“向上加速、向上延续、整理蓄势、向下加速、向下延续、下跌趋缓、反转中、震荡”等状态。
- 原始评分仅看柱状图斜率：上升 `+1`，下降 `-1`。

背离规则使用最近 20 根：

- 底背离：当前收盘接近该窗口最低价（≤ 最低价的 101%），且指标高于窗口最低值 10% 以上。
- 顶背离：当前收盘接近该窗口最高价（≥ 最高价的 99%），且指标低于窗口最高值 10% 以上。
- 持仓侧报告 MACD 顶背离，若周线亦为顶背离则升级为极高风险。旧信号引擎和趋势场景还会给出 MACD 底背离。

### 3.4 RSI

- 先计算收盘价差分的正收益与负收益绝对值；二者均采用 **简单滚动均值**，并非 Wilder 平滑。
- `RS = average_gain / average_loss`，`RSI = 100 - 100/(1+RS)`；周期为 14，权重 `1.0`。
- 报告阈值：`RSI > 70` 为超买，`RSI < 30` 为超卖，其余中性。
- 候选池评分：`<30: +2`，`30~50: +1`，`>70: -2`；持仓：`>70: -1`，`<30: +1`（超卖反转）。
- 持仓有 RSI 顶背离风险提示；旧引擎同时有 RSI 底背离。

### 3.5 ADX、+DI 与 -DI

ADX 由 14 日 Wilder RMA 计算：

1. 计算 TR、`+DM`（当日高点上移占优且大于 0）和 `-DM`（低点下移占优且大于 0）。
2. 对三者做 Wilder RMA。
3. `+DI = 100 × smoothed(+DM)/smoothed(TR)`，`-DI` 同理。
4. `DX = 100 × |+DI - -DI| / (+DI + -DI)`，`ADX = RMA_14(DX)`。
5. 前 `2×14-1=27` 根数据视作预热期并置空。

个股分类由 ADX 强度与 `+DI - -DI` 共同决定：

| ADX | DI 条件 | 状态 |
|---|---|---|
| `<15` | 任意 | 无趋势 / 横盘 |
| `15~25` | DI 差 > 0 / < 0 | 弱多头 / 弱空头 |
| `25~50` | `+DI - -DI > 5` / `< -5` | 中等多头 / 中等空头 |
| `≥50` | `+DI - -DI > 5` / `< -5` | 强多头 / 强空头 |
| `≥25` | `|+DI - -DI| ≤ 5` | 趋势不明、多空僵持 |

- ADX 指标权重为 `2.0`。当 `ADX≥25` 时，多头原始分 `+2`、空头 `-2`；15~25 仅标注“趋势萌芽”，无分数。
- 个股 ADX 读取 SQLite 的 `adx_score`；指定日期缺失时退回该标的最新记录。ETF 缺失被当作正常情况。
- 市场广度：当日全部 `adx_score` 按上述分类统计；多头数超过空头数 1.5 倍判为偏多，反之偏空；否则强/中趋势标的超过全体 30% 时判为分化，否则无明确方向。
- 指数 ADX：取 60 日指数 K 线本地计算。展示时对 ADX 乘 `1.2` 仅用于颜色强弱，原始数值不变；DI 方向阈值为 5。指数短评还会检测 DI 方向切换、接近方向历史 ADX 极值（>历史最大值 90%）、3 日连续增减及相对方向中位数。

### 3.6 成交量、量比与 OBV

- 量比：`当日成交量 / 前 n 日平均成交量`；支持 `n=5、20`，样本不足、均量为零或空值时回退为 `1.0`。
- 持仓的“放量滞涨”：5 日量比 `>1.5` 且当日 `change_pct <1%`。
- 候选池的“放量异动”：5 日量比 `>1.5`，且今日量大于此前 4 日均量的 1.5 倍；原始分 `+0.5`，权重 `0.5`。
- OBV：上涨日加当日量、下跌日减当日量、平盘不变；另计算 30 日 OBV 均线。OBV 被存储和读取，但当前没有进入信号或评分。

### 3.7 K 线形态与结构性风险

- 实体：`|close-open|`；上影：`high-max(open, close)`；下影：`min(open, close)-low`。
- 当前 K 线中任一影线大于实体两倍即为长影线（实体为零时不认定）。
- 候选池长下影线给出“底部有支撑”信号，原始分 `+0.5`、权重 `0.5`。
- 高位长上影：最近 20 根必须足够；影线至少占价格 3%，并且收盘位于 20 日最高价的 90% 以上。阴线要求影线至少等于实体，阳线要求至少两倍实体。
- 大阳线破位：最近 20 根中寻找靠近新高（高点≥窗口新高 95%）且涨幅≥5%的阳线，现价跌破该阳线开盘价时报警。
- 中阳线破位：最近 20 根任意涨幅 `2.5%~5%` 的阳线，现价跌破其开盘价时报警。

## 4. 综合评分

总分为所有启用指标的 `原始分 × YAML 权重` 之和；没有统一的归一化区间或总分阈值。它是“指标一致性强弱”，不是概率或收益预测。

| 指标 | 权重 | 原始分的主要范围 | 最大加权贡献 |
|---|---:|---:|---:|
| SuperTrend | 2.0 | `+2 / -2` | `+4 / -4` |
| RSI | 1.0 | 候选 `+2~ -2`；持仓 `+1 / -1` | `+2 / -2` |
| MACD | 1.0 | `+1 / -1` | `+1 / -1` |
| MA | 1.0 | 多项相加，约 `+3.5 / -3` | 同左 |
| ADX | 2.0 | `+2 / -2` | `+4 / -4` |
| 量比 | 0.5 | 候选 `+0.5 / 0` | `+0.25 / 0` |
| K 线 | 0.5 | 候选 `+0.5 / 0` | `+0.25 / 0` |

因此 SuperTrend 与 ADX 各自的最大影响为 4 分，明显高于 MACD；候选池分数会因 RSI、量比、长下影等“抄底倾向”变高，持仓则更侧重趋势翻空、均线破位与顶背离风险。

## 5. 趋势场景分析

### 5.1 四因子趋势分类

最少需要 60 根日 K。总分为 0~100 的加权和：

| 因子 | 权重 | 关键规则 |
|---|---:|---|
| MA 排列 | 30% | `MA5>MA10>MA20>MA60` 且价格在 MA5 上方为 100；完全空头且价格在 MA5 下方为 0；其余按 4 个多头条件计 `40+12×数量`。 |
| MA 斜率 | 25% | MA5/10/20 全上为 100，全下为 0；两条上为 75，两条下为 25，其他 50。 |
| SuperTrend | 25% | 90 日 ATR、近 10 日多/空方向；至少 8 日多为 100，至少 8 日空为 0。 |
| 价格位置 | 20% | 价格位于 4 条均线上方为 100，下方为 0，中间为每条上方 25 分。 |

总分 `≥60` 为上升趋势，`≤40` 为下降趋势，之间为横盘；`≥70` 或 `≤30` 定义强势，60~70 或 30~40 为中等。

### 5.2 上升趋势场景

- **趋势强度**：最近 20 日涨幅与 MA5/10/20/60 平均间距；间距<3% 且涨幅>10% 为强势，间距<5% 且涨幅>5% 为中等。
- **顶部结构**：近 10 日后 3 日均量比前段增加>30%、但 3 日涨幅<3% 时量价背离；收盘高于 20 日高点 95% 且 10 日收盘波动率<2% 为高位横盘；另尝试 MACD 顶背离。
- **拐点风险**：MA5 向下、由上向下跌破 MA10/MA20、高位长上影、SuperTrend 翻空。

### 5.3 下降趋势场景

- **下跌强度**：最近 20 日跌幅、均线平均间距、近 10 日阴线比例；间距<3%、跌幅<-10%、阴线>60% 为强势下跌，较宽条件为<5% / <-5% / >50%。
- **底部结构**：前 10 日与后 10 日跌幅比较以识别下跌放缓；近 10 日均量相对近 20 日均量<0.6 为缩量；近 10 日至少 3 根长下影；另尝试 MACD 底背离。
- **企稳确认**：3/5 日不创新低、多根 MA 向上或走平、5 日均量相对更早区间为 1.2~1.8、MA5 上穿 MA10 或 MA20。

### 5.4 横盘场景

- 用最近最多 30 日的低点 10%/25% 分位数定义底部区间，高点 75%/90% 分位数定义顶部区间；核心宽度为高点 75% 与低点 25% 的差相对低点的百分比。
- 收盘高于顶部区间下界认作向上突破；近 3 日均量相对前段量比≥1.5 时确认放量；回踩顶部区间而未有效跌破、以及 `MA5>MA10>MA20` 为辅助多头信号。
- 收盘低于底部区间上界认作向下突破；量比≥1.2 时确认放量下跌；反弹受阻和 `MA5<MA10<MA20` 为辅助空头信号。

## 6. 数据、调用和缓存边界

- 指标所需最小列：日 K 的 `open/high/low/close/volume`；周线由日线按 ISO 年周聚合（开盘首值、高低极值、收盘末值、成交量求和）。
- `technical_indicators` 表可缓存 MA、SuperTrend、MACD、RSI、量比、K线与 OBV；命令行 `pool_manager.py test-indicators --save` 可写入。
- 正式报告使用 `force_realtime=True`，MA、SuperTrend、MACD、RSI、量比和 K 线不读取该缓存。
- ADX 个股依赖共享 SQLite `adx_score` 表，因此它的日期可能与本次 K 线不同；指数 ADX 不依赖该表，而在 60 日指数 K 线上计算。

## 7. 实现核查：需要关注的偏差与风险

以下均为源码层面的可复现问题或配置/实现不一致，未对业务逻辑作修改。

1. **文档与目录已过期**：`WatchMonitor/README.md` 声称指标位于 `core/indicators/`，实际该目录不存在；真实实现位于同级 `trading_ai_toolkit\indicators`，`core/indicator_funcs.py` 只是转发层。部署、打包或单独运行 WatchMonitor 时必须确保项目父目录在 Python 导入路径中。
2. **SuperTrend 参数不一致**：YAML 实时方向设为 ATR(10, 3)，但预计算缓存、翻转检测与趋势检测使用 ATR(90, 3)；周线翻转为 ATR(20, 3)。同名指标可能产生不同方向或翻转时间。
3. **MACD 场景代码与工具接口不匹配**：`calculate_macd()` 返回字典（并含 `dif_series`），而 `uptrend.py` 和 `downtrend.py` 把返回值当作 DataFrame，调用 `len(... )`、`.tail()` 和 `['macd_dif']`。异常被裸 `except` 吞掉，趋势场景中的 MACD 顶/底背离实际不会生成。
4. **K 线破位信号存在字段错误**：大/中阳线检查函数返回 `big_bull_open`、`medium_bull_open`，但 `CandleIndicator` 读取 `open_price`。在满足破位条件的持仓上会触发 `KeyError`，该指标实例的后续处理可能被管理器捕获并跳过。
5. **配置没有完全生效**：RSI 指标无论 YAML `period` 如何设置，都将结果存入 `rsi_14`；MACD 的斜率计算又固定调用默认 `12/26/9`，不会跟随自定义 MACD 参数。趋势场景 YAML 中的多项阈值（例如 `range_width_threshold`、`ma_breakdown_periods`）亦未在场景实现中读取。
6. **ADX 配置与实现的分工不完整**：`indicators.yaml` 的 ADX 三个阈值写在配置中，但 `ADXIndicator` 实际采用 `classify_trend()` 中硬编码的 15/25/50 和 DI 差 5。调整 YAML 不会改变 ADX 分类或评分。
7. **评分含义应明确标注**：总分未经归一化，且持仓与候选池使用不同规则；不能跨池比较，更不能解释为胜率。报告应同时保留各指标评分原因。
8. **背离算法是近极值比较而非严格枢轴背离**：它不要求两个明确的价格/指标转折点，容易在趋势延续或波动较小的品种中产生敏感信号。建议把背离作为确认项，结合趋势、成交量和止损规则使用。
